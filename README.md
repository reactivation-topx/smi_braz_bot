# СМИ Бот · Бразилия

Telegram-бот для менеджеров: громкие инфоповоды Бразилии, праздники, фестивали и чемпионаты — в едином формате, с карточками-картинками и напоминаниями **заранее** (по умолчанию за 5, 3 и 1 день и ещё раз в день события).

## Что умеет

| Что | Когда приходит |
|---|---|
| ⚡ **Срочные новости** (важность 8–10 из 10: смерть звезды, катастрофа, итог финала, громкий скандал) | сразу, круглосуточно — даже в 3 часа ночи |
| 📰 **Дайджест** — 8 главных новостей за сутки с переводом на русский | каждое утро в 09:00 |
| 🗓 **Напоминания** о праздниках, фестивалях, матчах, коммерческих датах | за 5, 3 и 1 день и в день события, в 10:00 |
| 📅 **Обзор недели** | по понедельникам |
| 📍 **Региональное** — праздники штатов и местные новости | только тем, кто выбрал этот штат |

Каждое сообщение — это карточка-картинка в одном стиле и подпись: что, когда, где, зачем это знать и **подсказка менеджерам**.

Команды для всех: `/week` `/month` `/news` `/states` `/settings` `/help`.

### Откуда берутся данные
- **Календарь** — файл `data/events.yaml`: федеральные праздники, праздники всех штатов, карнавал, Сан-Жуан, Паринтинс, Сирио-де-Назаре, коммерческие даты (Black Friday, День матери, 13-я зарплата…), финалы турниров, фестивали. Переходящие даты (карнавал, Пасха, Black Friday) **считаются автоматически на любой год**.
- **Новости** — RSS-ленты (`data/sources.yaml`): Google Новости, g1, ge, Folha, CNN Brasil, Agência Brasil, Metrópoles. Бот опрашивает их каждые 10 минут.

### Как бот понимает, что новость громкая (бесплатно, без ИИ)
1. **Склеивает** одинаковые истории из разных изданий — одна история = одно сообщение, без повторов.
2. **Считает охват**: чем больше разных изданий подхватили историю, тем она важнее (1 издание → 3 балла, 6+ изданий → 8).
3. **Сверяется с трендами Google по Бразилии**: если тему массово ищут — до +3 баллов.
4. **Учитывает слова**: «morre», «tragédia», «campeão», «aposentadoria» и громкие имена (Неймар, Лула, «Фламенго»…) повышают важность; рецепты, гороскопы и промо — понижают.
5. **Определяет тему и штат** (спорт, политика, стихия…; «chuvas no Rio Grande do Sul» → RS).

Важность 8+ — срочное сообщение сразу, 5+ — в утренний дайджест. История, которая разгоняется постепенно, станет срочной в момент, когда её подхватит достаточно изданий.

**Перевод** — бесплатный онлайн-переводчик MyMemory. Бот переводит только то, что реально отправляет (срочные и дайджест), — это несколько тысяч символов в день, в бесплатный лимит укладывается с запасом. Перевод машинный, поэтому под ним всегда показывается оригинальный заголовок на португальском. Если лимит вдруг закончится, до конца суток заголовки придут на португальском.

**Платный режим (по желанию, позже).** Если вписать в `.env` ключ Claude (`ANTHROPIC_API_KEY`), бот сам переключится на него: точнее отбор, качественный перевод, пояснение «что случилось и почему важно» и автоматическое добавление в календарь концертов и матчей из новостей. Стоит это примерно $1–3 в месяц.

## Бесплатный запуск на GitHub (без сервера и без карты)

GitHub бесплатно запускает бота по расписанию: примерно каждые 10 минут он стартует и работает 8 минут — отвечает на команды, собирает новости, отправляет срочные, дайджест и напоминания. Подписчики и отправленные напоминания хранятся в кэше GitHub в зашифрованном виде.

**Чем отличается от своего сервера:** между запусками бывают паузы в 2–15 минут (GitHub иногда задерживает расписание), поэтому ответ на команду или срочная новость может прийти с такой задержкой. Всё остальное работает так же.

### Шаги
1. Создайте токен бота у [@BotFather](https://t.me/BotFather) и узнайте свой ID у [@userinfobot](https://t.me/userinfobot).
2. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно, карта не нужна).
3. *New repository* → имя, например `smi-bot` → **Public** (для публичных репозиториев минуты GitHub Actions бесплатны без лимита; код бота станет виден всем, а токен и база — нет) → *Create repository*.
4. *uploading an existing file* → перетащите **содержимое** папки `smi_bot` (папки `bot`, `data`, `assets`, `tests` и файлы) → *Commit changes*.
   Папка `.github` скрытая и может не перетащиться. Тогда: *Add file → Create new file*, в имени файла введите `.github/workflows/bot.yml`, вставьте содержимое этого файла из архива → *Commit changes*.
5. *Settings → Secrets and variables → Actions → New repository secret* — добавьте:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_IDS` — ваш Telegram ID;
   - `STATE_KEY` — любой длинный пароль (20+ символов), им шифруется база; сохраните его;
   - по желанию `TRANSLATE_EMAIL` (любая ваша почта — больше бесплатного перевода) и `ACCESS_CODE`.
6. Вкладка *Actions* → если просит, нажмите *I understand… enable them* → слева **smi-bot** → *Run workflow*.
7. Через минуту напишите боту `/start`. Дальше всё запускается само.

Настройки (часовой пояс, время рассылок, дни напоминаний) — во вкладке *Variables* того же раздела: `TIMEZONE`, `REMIND_TIME`, `DIGEST_TIME`, `REMIND_DAYS`, `BREAKING_THRESHOLD`.

> GitHub отключает расписание в репозитории, где 60 дней не было изменений, и пришлёт об этом письмо — достаточно нажать *Enable workflow* или сделать любую правку (например, добавить событие в `data/events.yaml`).
> GitHub Actions задуман для сборки и проверки кода; запуск ботов по расписанию — распространённая практика, но формально это серая зона его правил. Для постоянной работы надёжнее свой сервер (ниже).

## Запуск на своём сервере (постоянная работа, без задержек)


### 1. Подготовить ключи
1. **Токен бота**: в Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → имя «СМИ Бот» → получите токен.
2. **Ваш Telegram ID**: напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт число.

Больше ничего не нужно — режим без платных ключей включён по умолчанию.

### 2. Сервер: Vultr, $5 в месяц
1. Зарегистрируйтесь на [vultr.com](https://www.vultr.com) и привяжите карту.
2. *Deploy → Cloud Compute → Shared CPU (Regular)*.
3. Локация — **São Paulo** (ближе всего к бразильским сайтам; подойдёт и любая другая).
4. Образ — **Ubuntu 24.04**, тариф — **1 vCPU / 1 GB / $5 в месяц** (с IPv4).
5. Добавьте SSH-ключ или запомните пароль root из карточки сервера → *Deploy*.
6. Подключитесь: `ssh root@<IP-сервера>`

Оплата почасовая: два месяца работы ≈ $10. Чтобы перестать платить, сервер нужно **удалить** (*Server → Destroy*) — выключенный сервер тоже оплачивается.

Боту хватает 1 GB памяти. Свой переводчик без лимитов (LibreTranslate) можно включить позже, но ему нужен сервер на 4 GB — см. комментарии в `docker-compose.yml`.

### 3. Установить и запустить
```bash
# на сервере
apt update && apt install -y docker.io docker-compose-v2 unzip

# загрузить архив с компьютера (выполнить на СВОЁМ компьютере):
#   scp smi_bot.zip root@<IP>:~
unzip smi_bot.zip && cd smi_bot
cp .env.example .env
nano .env          # вписать BOT_TOKEN, ADMIN_IDS и TRANSLATE_EMAIL (любая ваша почта), при желании ACCESS_CODE

docker compose up -d --build
docker compose logs -f     # проверить, что «СМИ Бот запущен»
```
Бот пришлёт администратору «✅ СМИ Бот запущен». Напишите ему `/start`, выберите штаты, затем `/fetch` и `/test` — увидите, как выглядят все типы сообщений.

Сразу после запуска бот не рассылает «срочным» всё, что накопилось за последние 12 часов, — только то, что выйдет дальше.

**Без Docker** (любой сервер с Python 3.11+): `pip install -r requirements.txt && python -m bot.main`.

### 4. Пригласить менеджеров
- Если задан `ACCESS_CODE`, отправьте ссылку вида `https://t.me/<имя_бота>?start=<КОД>` — доступ откроется сразу.
- Без кода бот открыт любому, кто его найдёт.

## Настройка

Все параметры — в `.env` (см. комментарии в `.env.example`). Самые полезные:

| Параметр | По умолчанию | Что меняет |
|---|---|---|
| `REMIND_DAYS` | `5,3,1,0` | за сколько дней напоминать (`0` — в день события); можно, например, `7,5,3,1,0` |
| `REMIND_TIME` / `DIGEST_TIME` | `10:00` / `09:00` | время рассылок |
| `TIMEZONE` | `America/Sao_Paulo` | пояс расписаний; для Москвы — `Europe/Moscow` |
| `BREAKING_THRESHOLD` | `8` | порог «срочности»: 9 — только самое громкое, 7 — больше новостей |
| `DIGEST_MIN_IMPORTANCE` | `5` | с какой важности новость попадает в дайджест |
| `QUIET_HOURS` | `off` | срочные приходят круглосуточно; при желании можно задать «тихие часы», например `23-8` |

После правки `.env`: `docker compose restart`.

### Добавить событие
- **Быстро, из Telegram** (администратор):
  `/add 12.12.2026 | Концерт Анитты в Рио | RJ | festival | Стадион Маракана`
  Диапазон дат: `05.02.2027-10.02.2027`. Категории: `holiday`, `festival`, `sport`, `commercial`, `culture`.
- **Насовсем, в календаре**: допишите блок в `data/events.yaml` (формат описан в начале файла) и отправьте боту `/reload`.

### Команды администратора
`/add` `/del N` `/custom` `/stats` `/sources` `/reload` `/fetch` `/test` `/broadcast текст` — подробности в `/help`.

## Расходы
- **Сервер Vultr — $5 в месяц.** Всё остальное бесплатно: перевод (MyMemory), RSS-ленты, тренды Google, картинки рисуются на сервере.
- **Если включить Claude** (необязательно): Haiku 5.5 стоит $0.10 за 1 млн входных токенов и $0.50 за 1 млн выходных — при ~1 000 заголовков в сутки это примерно $1–3 в месяц.

## Устройство проекта
```
bot/
  main.py            запуск, расписание
  app.py             рассылки: срочные, дайджест, напоминания, обзор недели
  handlers.py        команды и кнопки Telegram
  calendar_engine.py правила дат (Пасха, «2-е воскресенье мая»…), фильтр по штатам
  news.py            сбор RSS
  free_scoring.py    бесплатная оценка важности: склейка историй, охват, тренды, ключевые слова
  trends.py          тренды поиска Google по Бразилии
  translate.py       бесплатный перевод: MyMemory (онлайн) или свой LibreTranslate
  ai.py              платный режим: оценка и перевод через Claude
  cards.py           карточки-картинки
  formatting.py      единый текстовый формат
  db.py              SQLite
data/events.yaml     календарь (редактируется)
data/sources.yaml    RSS-ленты (редактируется)
tests/               проверки логики: python -m unittest discover -s tests
```

Даты разовых событий (финалы, фестивали 2026–2027) сверены с открытыми источниками на 5 ноября 2026. Праздники штатов — справочные, перед крупной акцией в конкретном штате их стоит перепроверить. Шрифт Inter — лицензия SIL OFL 1.1 (`assets/fonts/OFL.txt`).
